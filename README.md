# Network Infrastructure Project – IT & HR Offices

This repository contains the Cisco Packet Tracer (`.pkt`) file for the design and implementation of a network infrastructure connecting the IT and HR offices of a medium-sized organization. The project was created as part of the Cybersecurity / Networking program and demonstrates a fully functional, secure, and scalable network.

## Project Overview

The network includes:

- IT Office and HR Office with wired and wireless connectivity
- Routers, switches, and lightweight access points
- Centralized Wireless LAN Controller (WLC)
- VLAN segmentation for department isolation
- DHCP, DNS, and File & Print services
- Cloud Data Center connectivity

The design focuses on:

- Reliable inter-office communication
- Logical and physical organization of network devices
- Secure network segmentation and access controls
- Centralized management and monitoring

## Key Features

- VLANs for IT and HR isolation
- DHCP and static IP addressing
- Secure wireless networks (WPA2 Enterprise for employees, guest network with internet-only access)
- ACLs and firewall rules for traffic control
- Monitoring and management via SNMP, Syslog, and NetFlow

## File Contents

- `Network_Infrastructure_IT_HR.pkt` – Cisco Packet Tracer file containing the full network simulation
- Documentation of device configurations, port connections, and logical/physical diagrams is included in the README and project report

## Usage

1. Open the `.pkt` file in Cisco Packet Tracer.
2. Review the logical and physical topology of the IT and HR networks.
3. Simulate network traffic to verify connectivity and functionality.
4. Explore device configurations and VLAN/ACL setups for educational purposes.
